Where this data lives

Everything you see here is stored in localStorage in this browser — there is no server behind it. That is what makes the demo work on GitHub Pages, and also what makes it a demo: the data is not shared between devices, and clearing your browser data wipes it. The README explains how to swap in a real backend (Firebase, Supabase or your own API) without rewriting the front end.
